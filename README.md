# Podcast digest

Daily summaries of roughly 25 macro and markets podcasts, generated each
morning and published here as static pages.

**[Today's digest](https://joeedessa.github.io/podcast-digest/)** ·
**[Archive](https://joeedessa.github.io/podcast-digest/archive.html)**

---

## What this is, precisely

A language model transcribes each episode, summarises it, and a second pass
synthesises the day into one document. No human reads any of it before it is
published.

## What that means for accuracy

These numbers come from checking the output against transcripts by hand, not
from a vendor's claims:

| | |
|---|---|
| Calls attributed to the wrong speaker | **~6%** |
| Quotes that do not appear in the source | ~1 in 1,400 |
| Coverage of what was actually said | ~81% overall, **~69% on dense episodes** |
| Names garbled by speech-to-text | occasional, e.g. a misheard surname printed as fact |

Podcast transcripts carry no speaker labels. Who said what is **inferred** from
introductions, self-references and context. On a four-person panel that
inference is materially less reliable than in a two-person interview.

## How to read it

Every line is a **pointer back to the original episode**, not a record of what
someone said. If a call matters to you, listen to the source before acting on
it or repeating it.

Nothing here is investment advice. No one named on these pages has reviewed,
approved, or is aware of what is attributed to them.

## Corrections

If you are named here and something is wrong — a call you did not make, a view
misstated, a name misspelled — please
[open an issue](https://github.com/joeedessa/podcast-digest/issues) and it will
be corrected or removed.

## Source

Episodes are public podcasts. Only the generated digests are published here;
transcripts, summaries and the underlying database are not.
